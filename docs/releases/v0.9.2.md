A task actor speaks A2A (Agent2Agent protocol 0.3) with the core as its client, as the core's ADR-109 now writes it. The private frame wire and the verifier file are gone.

- **A2A task actor.** `--task-actor` replaces `--task-verifier-file`. The actor serves the agent card (`/.well-known/agent-card.json`: push notifications, one required extension), a JSON-RPC endpoint (`message/send`, `tasks/get`, `tasks/cancel`) and the probe. It takes the core's one message, confirms the task with the core (`GET /v2/messenger/spot/link/tasks/{key}`, with the message's bearer), and runs the goal the core answered. A core that refuses, a goal or a workspace that differs, and a second message end the A2A task `rejected`.
- **No wake report.** The task ends `completed` (`failed` for a failed run) with one artifact `{memory, line}`, and the SDK's push notification tells the core. The memory item and the line in the bus are as before. `tasks/cancel` stops the turn at its next step and ends the task `canceled`.
- **`start_task` waits for the core.** On the substrate the tool is offered only while the core's hello says it makes task actors (`tasks: true`). A Deployment spot is unchanged.

Upgrade: image `ghcr.io/triageagent-dev/spot:0.9.2`, chart `oci://ghcr.io/triageagent-dev/charts/tria-spot` 0.9.2. The ActorTemplate of a task actor runs the same image with `--task-actor` instead of `--task-verifier-file`; the template of the persona spot does not change.
