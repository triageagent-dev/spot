Hardening of the substrate link and the task actor.

- **Frame tokens.** A core-signed frame token is taken once and only while it ends within the hour; a saved token that reads as a signed one is taken on a cold start only while it verifies. The hello token of a core from before signed tokens is unchanged.
- **Task actors and the ceilings.** At the daily or hourly ceiling a task actor does not run its task and says so in its bus line; a substrate spot at a ceiling does not ask the core for a task actor and says so in its digest. The task's artifact carries `usage` (`model`, `input`, `cached`, `output`, `steps`, `toolCalls`) for the core's books.
- **Task messages.** `message/send` is confirmed with the core before anything is recorded for it; a message that is not confirmed, names no task, carries no bearer, or whose push configuration is not the core's callback for that task (`<core-api-url>/v2/messenger/spot/link/tasks/{key}/events`) is answered with a JSON-RPC error. The push sender follows no redirect.
- **Workspace.** A call to the core that names a workspace, under any spelling of the key, goes with the spot's own workspace, in every spot.
- **Prompts and gates.** The task prompt gives the title and the goal as quoted text. The standing notes the supervisor reads let the core's tools through the recall gate; a connector's tools wait for the model's own `search_memory`.
