The chart renders the agent card's arguments as one quoted argument each.

- **Chart fix.** `spot.description` and `spot.skills` (0.9.6) were rendered unquoted, so a description with ": " in it, or any skills list, read as YAML inside the container's args and the upgrade failed with "expected string, got map". Both now render as one quoted argument (`--description=…`, `--skills-json=…`). `make check` renders `ci/card-values.yaml`, a description with a colon and a skills list, and asserts the quoting.

Upgrade: chart `oci://ghcr.io/triageagent-dev/charts/tria-spot` 0.9.7, image `ghcr.io/triageagent-dev/spot:0.9.7` (the binary is 0.9.6 unchanged).
