The one-time enrollment key is a Helm value: one command installs a spot.

- **`core.enrollKey`.** The key a workspace admin minted in the core for the spot's name goes in as a value, `helm upgrade --install <name> oci://ghcr.io/triageagent-dev/charts/tria-spot --version 0.9.8 -n <namespace> --set core.enrollKey=<key> …`, and the chart makes the Secret `<name>-enroll-key` and mounts it. No Secret made by hand. The first join spends the key; the value can be dropped afterwards, the spot keeps its certificate on its volume. `core.enrollKeySecret` stays for an install that keeps secrets out of Helm values.
- **Chart check.** `ci/enroll-values.yaml` renders the Secret, the mount and the argument; a release without the value renders no enrollment Secret.
