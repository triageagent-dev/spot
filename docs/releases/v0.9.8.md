The one-time enrollment key is a Helm value, and the spot reads each message of a room once.

- **`core.enrollKey`.** The key a workspace admin minted in the core for the spot's name goes in as a value, `helm upgrade --install <name> oci://ghcr.io/triageagent-dev/charts/tria-spot --version 0.9.8 -n <namespace> --set core.enrollKey=<key> …`, and the chart makes the Secret `<name>-enroll-key` and mounts it. No Secret made by hand. The first join spends the key; the value can be dropped afterwards, the spot keeps its certificate on its volume. `core.enrollKeySecret` stays for an install that keeps secrets out of Helm values.
- **Chart check.** `ci/enroll-values.yaml` renders the Secret, the mount and the argument; a release without the value renders no enrollment Secret.
- **Messages are read once.** The supervisor remembers the ids of the messages it has read in a room (the last 1,024), and a message the core sends again is not news: it starts no wake and no model call. What was in the room when the spot started is history in the same way. Before, the cursor was the only guard, so a core that sent a whole page on every read woke the model to answer an old request again at every poll.
- **Quieter log.** The "early wakes capped for this hour" warning is logged at most once every ten minutes, not once a second while edges are held.
