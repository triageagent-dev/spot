The last release with the Temporal engine, and the spot's join by certificate.

**This is the last release that can run the Temporal engine** (`engine.type: temporal`). From v0.7.0 the core is the spot's scheduler (the core's ADR-106) and the engine is gone. A customer who runs Temporal stays on this release.

**Certificate identity** (the core's ADR-105)
- A spot can join the core by certificate, with no static token: `core.identity: certificate`, `core.apiUrl`, `core.caFingerprint`. It keeps its own key and certificate in `/state/identity`.
- The spot sends its one-time enrollment key (`core.enrollKeySecret`, mounted as a file) with the first join. A workspace admin mints the key in the core.

**Tasks and the console**
- The stats frame lists the tasks the spot has in hand, and a wake line carries the key and title of the task it belongs to.

**Chart**
- `spot.replicas` keeps a parked spot at 0 across an upgrade.

**Fixes**
- A core token the core refused is not sent again until the token file changes, and a schedule in the past no longer makes the Temporal bridge poll in a loop.

Upgrade: image `ghcr.io/triageagent-dev/spot:0.6.1`, chart `oci://ghcr.io/triageagent-dev/charts/tria-spot` 0.6.1. A spot that upgrades the chart must pass its full values, not only a changed overlay.
