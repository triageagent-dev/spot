The core is the spot's scheduler, and the Temporal engine is removed.

**The core sends the wakes** (the core's ADR-106)
- Every wake report now carries the plan as it stands: `nextWhy` beside `next` and `nextSource`, and the `promise` the agent made a person (`at`, `why`, `human`). After the core's `hello` the spot sends one `schedule` frame with the same, the backoff of a failed wake and `--max-wake`, so a core that restarted gets the plan back.
- With the stream up the spot keeps no timer for the plan: the core sends `{"wake":{"reason":"tick"|"promise","why":"..."}}` when a wake is due, and the spot starts a wake of the long lane. A tick for a plan the spot has already replaced is dropped.
- Without the stream the spot wakes itself at the planned time, as before. With the stream up and no `wake` frame it wakes itself once `--max-wake` after its last wake, so a spot never sleeps for ever because the core is away or has no scheduler.
- The hold rule, the edges, the two lanes, the caps and ceilings, the quiet-wake skip, the notes, the prompt and the books stay in the spot.

**Tasks run in the local engine**
- `start_task` and the control operations (list, stop, kill, restart, drop) work as before, without a service: a task is a turn of its own beside the lanes, up to `--max-tasks`. Chart value `agent.maxTasks` (it was `engine.temporal.maxTasks`). The stats frame lists the turns of the two lanes as well as the tasks.
- A turn that a restart cuts is redone from its first step at the next wake.

**Removed**
- `--engine` and every `--temporal-*` flag: the spot refuses to start with one, and says why.
- The chart's `engine` block, `networkPolicy.temporal` and the Temporal ci values. A release whose values set `engine.type: temporal` fails to render with a message that names ADR-106. Remove the `engine` block from the values before upgrading; the Secrets of the Temporal API key and payload key are no longer mounted and can be deleted.
- `go.temporal.io/sdk` and `go.temporal.io/api`, the payload codec and the spot's Temporal ADR.

Upgrade: image `ghcr.io/triageagent-dev/spot:0.7.0`, chart `oci://ghcr.io/triageagent-dev/charts/tria-spot` 0.7.0. Roll the core with the wake job first. A spot that upgrades the chart must pass its full values, not only a changed overlay.
