A reply answers the request Tria is waiting for.

- **One answer per request while a newer one waits.** The model chooses the `reply_to` of a reply in the bus, and left alone it answered a request it had already answered, again, while Tria's newer request waited: Tria then carried the old answer to the person as the answer to the new question, and the new one was never worked on. The supervisor now keeps a book of the bus from every page it polls and every page the model reads: Tria's requests, and the spot's own replies by the request they answer. A reply to a request the spot has already answered is refused, as a tool result, while a newer request of Tria's is open (unanswered, due, below the hop limit); the refusal names the open request, quotes it and says to answer that one, or to post the new word on the old request with no `reply_to`. A reply to an unanswered request, to one the book does not know, or to an answered request with nothing newer open goes as before, so a partial answer can still be completed.
