A message in a room the spot does not read no longer stops it, and an issue that changed while an actor slept rides with the wake.

- **News from another room no longer stops the spot.** The core names the rooms that have a new message. When it named one the spot does not read, such as the team room, while a turn was running, the spot exited. It now ignores that room and the turn goes on.
- **A tick of an actor carries the issues that changed.** An actor is suspended between wakes and reads the open issues only once it runs. The wake the core ordered read the rooms before its turn and the issues after it, so an issue that had changed while the actor slept was found when the turn was over and started a second turn a few seconds later, with the whole prompt and tool list again. The ordered wake now reads the issues with the rooms, before its turn: the change is a fact of that turn.
