A spot reads the whole room, not only what is addressed to it.

- A person's message that the core addresses to another spot, or to nobody, no longer vanishes. It still never wakes the spot, but the next wake carries it as context, in order and marked "not addressed to you", so "my question above" and "check what Tria answered" resolve. Before, the spot answered that it could not find the question.
- A reply carries the message it answers (the core's `replyTo`): quoted when that message is in the same read, named by id otherwise.
- The wake prompt tells the spot to read the room with `read_workspace_room` when a person points at something that is not among the lines.

Upgrade: image `ghcr.io/triageagent-dev/spot:0.8.4`, chart `oci://ghcr.io/triageagent-dev/charts/tria-spot` 0.8.4. A spot on substrate points its ActorTemplate at the new image. Nothing else changes. A core that does not send `replyTo` shows replies as plain messages.
