A person is answered once when a deployment spot starts a task.

- **One answer.** On a deployment spot, a turn that has started a task posts no reply to the request: the task posts the answer, so Tria no longer tells the person twice (a quick line, then the result). The post is refused with a reason the model reads, a message that answers no request is not held, and a new turn starts clean. A substrate spot is unchanged: the core sees its task actors and holds the quick line back.
- **Prompts.** The `start_task` description on a deployment tells the model to put the request id in the goal and to start the task before posting anything; the task prompt says to post with `reply_to` that id when the goal names one.
